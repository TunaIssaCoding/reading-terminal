Connection & settings

Reading data stays in your private GitHub repository. This site only writes to user/. With no token, a separate fictional demo library is used.

Select only your private reading-data repository and grant Contents: read and write. The token is stored in this browser's localStorage. Use a trusted device; exports never contain it.

Portable by design

Export all user state and notes as JSON. Import merges with this library's existing notes; it never deletes them. Backups contain private text—store them securely.

See setup instructions for the private repository layout.
